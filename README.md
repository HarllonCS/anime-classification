# Best Anime List

This is a simple HTML project created to practice basic web page structuring without using CSS styling or JavaScript. The goal is to organize and showcase a list of my favorite anime using fundamental text formatting tags.

## Tech Stack

- **HTML5**: Page content structuring.

## Applied HTML Tags

This project exclusively uses the following structural tags:

- `<h1>` : Main title of the page.
- `<h2>` : Subheadings for categorizing sections or anime.
- `<h3>` : Lower-hierarchy headings for details or sub-sections.
- `<hr>` : Horizontal rules to visually separate sections.
- `<p>` : Paragraphs for descriptions, synopses, and personal thoughts.

## Getting Started

1. Clone this repository:
```bash
git clone https://github.com/HarllonCS/anime-classification.git
```

2. Open `index.html` in any web browser (Chrome, Firefox, Edge, Safari).
